# Póster de campaña · SPAN 2156 · Fall 2026

Dos páginas, sin carpetas:

- `index.html`: hoja de asignación y lista de voces (página principal).
- `deck.html`: presentación interactiva del taller (← →, N notas, F pantalla completa, Ctrl/Cmd+P para PDF).

## Publicar en GitHub Pages

1. Crea el repositorio **span2156-poster** (público) y sube `index.html`, `deck.html` y este `README.md`.
2. Settings → Pages → Deploy from a branch → `main` / `(root)`.
3. En un minuto: https://lisola628.github.io/span2156-poster/

`SPAN2156_Poster_Moodle_bloque.html` no va a GitHub: se pega en Moodle (Edit section → Source code).
